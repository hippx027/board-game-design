# READTHROUGH-003 — Holding, storm markers, start spacing, supply drops

Date 2026-09-29 · three Claude (Opus) agents, main rules only · logs `readthroughs/readthrough3-*.md`

| Game | Tester | Result |
|---|---|---|
| 2p | Rules lawyer | **No winner by round 25**: both players held 5 live cards, so they never drew Dead cards |
| 3p | Three styles | Cautious won in round 9 on 3 held Heal cards; 3 drops placed, 0 looted |
| 5p | First-timer | Won in round 9; storm marked 33 of 50 tiles |

## Design issues (for the designer)
1. **Holding 5 live cards makes you unkillable.** You never draw, so Dead cards never reach your hand (game-breaking)
2. **No end at round 25**
3. **Supply drops are placed spitefully**: placers put them on the storm rim, far from everyone
4. The active player can aim storm markers at an opponent's tile (possibly intended)
5. Doomed players must still play out their turn (a concession option?)

## Wording fixes applied
Gold deck contents · hex distance for start spacing and range · "played" includes partly used cards · hand-limit sentence removed (it never applied) · multiple loot piles on one tile · upgrades only during Actions · edge tile definition incl. holes · drop timing (before the start player's upkeep), count by starting players, placement passes to players still in, a new drop clears the old one · Quick Reference: reshuffle, skip after elimination, storm placement · range typo
