R1 A: play D1 D1 (move 3) to 3-icon tile, loot Attack top (A2). Hold H1 H1 S1. Storm: marker on edge tile beside B.
R1 B: play D1 D1 (move 3), loot Attack face-up (A2). Hold S1 S1 S1 (hoarding attacks). Storm: marker on edge adj A's route.
R2 A: draw 2 (S1 H1). Loot Heal (H2). Upgrade H1+H1+H1... hold H1 H1 H1 S1 S1, no draw pressure.
R2 B: draw 2 (D1 H1). Upgrade S1 S1 S1 + A2 (=5, overpay) -> Base Atk 2. Loot Move.
R3 drop: A places 2 gold (M3, A3) 3 tiles from A, toward A's side. B nudges 1 toward self. A reaches, takes A3. B takes M3 next turn.
R4 A: Base Shield via H1x3+H2 -> Shield 1. B storms A's tile (A must move each turn or eat 1 Dead).
R5 drop: B places; A nudges it onto a storm tile/away. B: Atk 2 + A2 + S1 = 5 at range 1 -> 4, A shield 1 -> 3 Dead to A discard.
R5 A: EXPLOIT: A holds 5 live cards (A3 H2 S1 S1 H1) and never plays them -> draws 0 cards forever -> Dead in discard never reach hand -> cannot be eliminated. Moves on Base Move only.
R6-R8 B: attacks every turn (base 2 at range <=1) + storm; A's discard fills with Dead, irrelevant.
R7+ storm 2/turn; board fully marked ~R12. B is drawing and reshuffling own storm Dead: R9 B upkeep 2 Dead in hand.
R9 B: copies turtle: plays nothing, holds 2 Dead + 3 live -> 2 < 3, never draws again.
R10-R25: both hold, walk, B pokes for Dead into A discard. Nobody can be eliminated.
R25: no rule for end of track. Stalemate, no winner.
