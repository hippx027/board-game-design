# Readthrough 4 — 2p exploit game (seed 1303, Characters variant)
Deal: A {Shade, Tide} keeps Shade; B {Ember, Bastion} keeps Ember. Start A. 30-tile board (15 each), pawns 3 apart.
Decks A: S D P D P | P S D S S ; B: P S D S P | P D S S D. Attack deck order 2,3,2,2,2,1,1,3,1,2,1,1; Heal 1,1,1,2,2,1,2,2. Gold H3 M2 H3 M2.
Stat line: M/A/S base, sh=current Shield, dead=hand/discard.

R1 A: move 3 (base1+D1+D1) to centre 3-icon tile; loot Attack (display 2,3 -> took 3). P,P as Shield -> sh2. Keep S. Storm on edge tile next to B.
R1 B: D+base=2 move; Ember loots twice: cube on tile1, step, cube on tile2 (assumed legal: "loot twice"). P,P shield -> sh2. Keep S,S (A at range 2, sh2: S+S+base=3-2=1 absorbed -> no attack). Storm aimed at A's region.
R2 A: draws S,D,S,S(reshuffle). Attack 1+3S=4, Shade +1 at range 2 -> 4-2+1=3, B sh2 absorbs 2 -> 1 Dead to B discard. (Shade applied before shield — assumed.)
R2 B: Ember double loot (Attack x2). Shield top-up sh2 unchanged. Attack base1+S,S=3 range1 -> 2 dmg, A sh2 -> 0. Storm placed.
R3 (drop 1, A places adjacent to self on non-edge; B nudges it 1 onto an EDGE tile next to B — nudge has no edge/storm restriction). B loots drop (M2) + cube (Ember twice incl. drop — assumed legal). A upgrades? no.
R3-R6: both loop Patch Up -> Shield, holding 3 Patch Ups between turns to refill sh to 4 whenever hit. Attacks: A lands 1-2 Dead per turn only via Shade overage; B mostly zeroed. B Ember out-loots A ~2:1 (B 11 cubes/cards by R6 vs A 6).
R5 drop 2: B places; A nudges onto storm tile. Both loot it (A M2? no—A H3; B H3 via 2nd loot same turn -> B takes BOTH gold cards in one turn with Ember).
R6 B upgrades Heal (H3+P1) -> Base Shield 1; R8 again -> Base Shield 2. A upgrades Attack (A3+S1) -> Base Attack 2 (R6), A3+A1 -> 3 (R9).
R7+: storm 2 markers/turn, 2 dmg, Shield no help. Each player places markers ON the opponent's tile; irrelevant because target just walks off before its own end of turn. Real pressure only once ring closes (~R10, 26/30 marked).
R10 A: hand has 2 Dead; heals 1 (P mode heal), attacks 3+2S+1(Shade)-range2=4 into B sh3 -> 1.
R11: board fully marked (30 tiles). Both take 2 storm Dead every turn. Race = who draws Heal cards. B has +4 Heal cards from double loot.
R12 A: draws 3 Dead + P1 + S. Heal 1 -> 2 Dead, attack; ends with 2 Dead. storm +2 to discard.
R13 A: draws into 4 Dead, 1 card (P). Heal 1 -> 3 Dead at end of turn -> A ELIMINATED. B wins (round 13).
Total: winner B (Ember). Key driver: Ember double loot incl. both gold cards in one turn; persistent Shield made combat near-irrelevant until storm.
